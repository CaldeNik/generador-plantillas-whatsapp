# 📲 Generador de Plantillas WhatsApp

Aplicación web para generar mensajes profesionales de WhatsApp a partir de plantillas dinámicas.

## ✨ Funcionalidades

- Generación automática de mensajes
- Múltiples plantillas
- Modo oscuro 🌙
- Copiado rápido al portapapeles
- Diseño moderno y responsive

## 🚀 Uso

1. Seleccionar plantilla
2. Completar datos
3. Generar mensaje
4. Copiar o enviar por WhatsApp

## 🛠 Tecnologías

- HTML
- CSS
- JavaScript
- Node.js (opcional para servidor local)
